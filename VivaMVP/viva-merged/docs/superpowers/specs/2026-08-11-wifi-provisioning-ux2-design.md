# WiFi 프로비저닝 UX 2차 — 좌우 분할 QR 화면 + 플랫폼 지름길

2026-08-11. 1차 실기기 피드백("수동 입력 번거로움") 후속. 브레인스토밍 결론:
접근 1(현 QR 흐름 유지 + 마찰 제거) 확정, BLE·SoftAP·DPP 는 제외(백로그).

## 배경 제약 (변경 불가)

- WiFi **비밀번호**는 iOS/Android 모두 앱이 읽을 수 없다 — 자동 추출 불가.
- iOS **SSID** 자동 채움은 Access WiFi Information 엔타이틀먼트 필요 —
  무료 Personal Team 은 발급 불가(빌드 실측), 유료 전환 계획 없음 → 영구 포기.
  `currentSsid.ts` 의 iOS gate 유지. Android 자동 채움 배관은 유지.
- 시나리오는 1회성 설정(집 와이파이) 최적화. 로봇은 연결한 네트워크를 기억한다.

## 목표

누구든지 안내만 따라가면 QR 생성 → 비바 스캔 → 연결까지 도달.
남는 입력 마찰(iOS 비번 타이핑 등)은 안내·붙여넣기·저장으로 최소화.

## 화면 구조 — WifiProvisionScreen 전면 재구성

2단계 화면(폼 → QR) 을 **좌우 분할 단일 화면**으로 바꾼다 (사용자 지정 레이아웃).

```
┌────────────────────────────────────────────────┐
│  비바를 새 와이파이에 연결해요              ✕  │
│                                                │
│  ┌─ 왼쪽 (폼, maxWidth 380) ─┐  ┌─ 오른쪽 ──┐ │
│  │ [Android 지름길 카드]      │  │ ┌┐    ┌┐ │ │
│  │ 와이파이 이름 [________]   │  │   QR     │ │
│  │ 비밀번호     [______][눈]  │  │  (대형)  │ │
│  │  helper: 비번 복사 안내    │  │ └┘    └┘ │ │
│  │ [ QR 만들기 ]              │  │  스캔 힌트│ │
│  └───────────────────────────┘  └───────────┘ │
└────────────────────────────────────────────────┘
```

### 왼쪽 폼

- SSID 입력: 기존 자동 채움(Android)·`ssidTouchedRef` 유지.
- 비밀번호 입력 + **보기 토글(눈 아이콘)**: 긴 비번 오타가 최다 실패 원인 —
  secureTextEntry 토글, 터치 타깃 44pt+.
- 비밀번호 helper (플랫폼 분기):
  - iOS: "iPhone 설정 > Wi-Fi > ⓘ > 비밀번호에서 복사해 붙여넣을 수 있어"
  - Android: "공유기 스티커나 와이파이 설정에서 비밀번호를 확인해줘"
- **Android 지름길 카드** (Android 만 렌더): "더 빠른 방법 — Wi-Fi 설정의
  QR 공유 화면을 비바에게 바로 보여줘도 돼" + "Wi-Fi 설정 열기" 버튼
  (`Linking.sendIntent('android.settings.WIFI_SETTINGS')`). iOS 는 렌더 안 함.
- "QR 만들기" 버튼: 첫 누름에 QR 표시. **표시된 뒤에는 입력 수정이 QR 에
  즉시 반영**(라이브) — "입력 고치기" 왕복 단계 삭제. 버튼은 그대로 남고
  누를 때마다 현재 입력을 저장(아래 저장 규칙)만 다시 수행한다.

### 오른쪽 QR 존 — 3 상태

1. **QR 이전 (플레이스홀더)**: 점선 테두리 빈 QR 자리 + 사용 순서 3단계
   (기존 QR_STEPS 문구 유지 — 실제 순서라 번호 정당).
2. **QR 표시**: QR 을 현재 240 → **가능한 최대 크기(높이 기준, 상한 320)**로.
   흰 서피스 카드 위에 렌더(로봇 카메라 인식 대비 극대화).
   아래 힌트 1줄: "화면 밝기 최대 · 비바에게 15~25cm 거리로 보여줘".
3. **성공**: 기존 connected 엣지 재사용 — 체크 + "비바가 연결됐어!" 후
   1.5초 뒤 자동 닫힘(CLOSE_AFTER_SUCCESS_MS 유지).

### 시그니처 요소 (frontend-design)

QR 카드를 **로봇 카메라 뷰파인더 프레임**으로: 네 모서리에 GREEN 코너 틱
(절제된 두께). 성공 시 틱이 채워지며 체크 표시. 이 화면이 기억되는 한 가지 —
나머지는 기존 토큰(#FAF7F0 / #369B75 / INK / Pretendard) 그대로, 새 색 없음.

## 입력 저장·복원

- "QR 만들기" 누를 때 `{ ssid, psk }` 를 AsyncStorage(`viva.wifiCreds`) 에 저장.
- 화면 열 때 저장분 있으면 둘 다 미리 채움 (sub 문구: "지난번 입력을 불러왔어").
  저장분이 SSID 자동 채움보다 우선(비번까지 있는 쪽이 가치 높음).
- 평문 저장 허용: 집 와이파이 비번, 기기 로컬, MVP — expo-secure-store 승격은
  필요해질 때. (`ponytail:` 주석으로 명시)
- 기존 "비번은 화면 떠나면 사라진다" 주석은 이 스펙으로 폐기 — 주석 갱신.

## 키보드 대응

랜드스케이프 키보드가 화면 대부분을 덮는다 — KeyboardAvoidingView 유지하되
좌우 분할이 깨지지 않게 폼 쪽만 밀어올린다. 입력 중 QR 존은 가려져도 무방
(QR 은 입력이 끝난 뒤 보는 것).

## 범위 제외

- BLE / SoftAP / DPP 프로비저닝 — 백로그.
- iOS 설정 딥링크(`App-Prefs:WIFI`) — 비공개 스킴, 버전별 불확실. 문구만.
- QR 스캔 실패 안내 화면(30초 힌트 등) — 기존 백로그 유지.

## 테스트

- 기존 WifiProvisionScreen 테스트 갱신: 2단계 → 좌우 분할 전제로.
- 신규: 저장분 복원 프리필, 눈 토글 secureTextEntry 전환, QR 라이브 갱신,
  Android 지름길 카드 플랫폼 분기(iOS 미렌더).
- 저장 유틸(wifiCredsStore)은 AsyncStorage 모킹으로 단위 테스트.
